# Scene Video Prompt Template

Animate the approved still and matching PNG character turnaround references into a gentle **[SHOT DURATION]** preschool music-video shot for **[EPISODE TITLE]**.

- **Full episode:** 16:9 landscape, total runtime 1:30–2:00 (90–120 seconds); make separate vertical 9:16 Shorts.
- **Active character names:** [exact names from the character bible, or “none”].
- **Reference images:** attach each active character's PNG turnaround from `assets/character-sheets/`; optionally include `cast-lineup.png`.
- **Lyric/audio cue:** [exact timed verse or instrumental cue].
- **Action:** [one readable action synchronized to the lyric].
- **Character motion:** [small, natural gestures; keep face, hair/fur, outfit, proportions, and identity unchanged].
- **Camera:** [locked / slow push-in / gentle pan / simple follow]; stable and unhurried.
- **Environment motion:** [subtle leaf movement, bubbles, or clouds only if useful].
- **Timing:** state the shot duration; begin on the first beat/action and hold the ending pose long enough for a clean edit.
- **Continuity:** preserve character identity, screen direction, and garden layout across neighboring shots.
- **Frame:** state 16:9 landscape explicitly.
- **Avoid:** fast cuts, flicker, sudden zooms, lip-sync changes, new characters, extra props, text, logos, unsafe actions, or harsh audio cues.
