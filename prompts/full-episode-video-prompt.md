# Full-Episode Video Prompt

Copy this master prompt into your video-planning assistant, replace the bracketed fields, and attach the relevant character-sheet references.

```text
Create an original nursery-rhyme song video for YouTube.

FORMAT AND LENGTH
- Complete finished video: 1:30–2:00 (90–120 seconds).
- Aspect ratio: 16:9 landscape.
- This is a full song episode, not a vertical Short.
- Plan a complete beginning, repeated chorus, and calm musical ending. Sum all shot durations to the requested runtime.

CHANNEL AND CAST
- Channel world: Milo & Friends Nursery Rhymes, Peach Stone Garden Lane.
- Named cast: Milo, Lila, Pip, and Bubo. Use only the characters named for this episode.
- Character designs: attach and follow the matching sheet from assets/character-sheets/. Keep faces, eye/hair/feather colors, fixed outfits, silhouettes, scale, and proportions unchanged.
- In every shot prompt, write the exact active character names. If nobody appears, write “On-screen characters: none.”
- Never substitute an unnamed “child,” “bird,” or “owl” for a named character.

STORY AND SONG
- Theme: [one simple preschool-friendly idea]
- Learning or feeling goal: [one idea]
- Language: [language]
- Write fully original verses and melody direction. Do not copy lyrics or melody from an existing nursery rhyme.
- Provide a timestamped verse/chorus map whose sections total 90–120 seconds.
- Include a character's name naturally in the verse when that character appears or acts.
- Match every lyric phrase to a clear, gentle visual action.

SHOT PROMPTS
For each shot, provide: timestamp, duration, lyric/audio cue, exact on-screen character names, action, composition, camera movement, setting, continuity note, and sound cue.
Every individual video prompt must repeat:
“16:9 landscape; [shot duration]; on-screen characters: [exact names or none]. Use the attached approved character-sheet references. Preserve each named character’s face, colors, fixed outfit, proportions, and screen direction; do not redesign them.”
Use only calm, readable movement. Keep the garden layout and lighting coherent across adjacent shots.

OUTPUT ORDER
1. Brief creative treatment
2. Complete original timed lyrics and verse map
3. Total-runtime calculation
4. Character list and reference-sheet filenames
5. Timed storyboard
6. Individual image and video prompts
7. Audio, thumbnail, and publishing notes

Do not render lyrics, captions, logos, or decorative lettering inside generated footage. Add captions in the editor after audio timing is locked. State which character-sheet references must be attached to each shot. If a generation tool cannot maintain character identity reliably, flag the affected shots for review before full production.
```
