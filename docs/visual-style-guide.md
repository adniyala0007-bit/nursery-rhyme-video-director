# Visual Style Guide

## Core direction

Polished 3D preschool storybook animation, soft forms, sunny natural light, saturated but balanced colors, welcoming expressions, simple staging, and clear actions. Every frame should read quickly on a phone screen.

## Approved recurring world and environment library

**Peach Stone Garden Lane** is the default home setting and continuity anchor: a peach-colored stone path curves through emerald meadow grass. A large rounded oak stands on the left. Pastel flowers, low cream fences, rounded bushes, and a distant cottage with a mint roof frame the path. Warm morning light and fluffy white clouds create a calm, cheerful atmosphere.

The [environment prompt library](../prompts/environments.md) also includes a Sunny Farmyard, Cozy Bedtime Bedroom, Rainbow Meadow Playground, and Sparkling Seaside Cove. Choose one primary setting that fits each song. Attach its PNG reference in every shot and preserve the same landmarks, layout, perspective, palette, and lighting across the episode. Add only the props a scene needs; avoid changing the approved set without a deliberate story reason.

## Composition rules

- Default full episode: 16:9 landscape, 1920×1080 or higher.
- Shorts: 9:16 portrait, 1080×1920; recompose for portrait rather than cropping faces.
- Keep one main action per shot and silhouettes separated from the background.
- Use wide shots to establish the garden, medium shots for character interaction, and close-ups for an important prop or expression.
- Leave uncluttered space where captions may appear. Keep text out of the image-generation prompt unless the tool reliably renders lettering.
- Use slow, stable camera movement. Avoid rapid flashing, strobing, disorienting motion, or abrupt loud sound effects.
- Keep important action centered in safe regions for mobile playback and later Shorts crops.

## Thumbnail rules

- One expressive face or clear character grouping; one large story prop; one readable action.
- Strong contrast between the subject and background.
- No tiny lettering, misleading expressions, unrelated props, or copied layouts.
- Provide a clean version without text so title experiments can be done in an editor.

## Negative prompt starter

`No extra fingers or limbs, no duplicate characters, no distorted faces, no text, no logos, no watermark, no frightening imagery, no harsh flashing lights, no unsafe behavior, no photorealistic adults, and no changes to the canonical PNG reference designs, species, hairstyles/fur, outfits, or palette.`
